# Local network inputs

The application loader reads these files locally; it never downloads data at runtime.

- `sites.csv` reproduces the assignment's site table.
- `nobel-eu.txt` is an unchanged provisional SNDlib native-text snapshot retrieved
  on 2026-10-27 from the [sikorski-as/sndlib mirror](https://github.com/sikorski-as/sndlib/blob/b8227125f9d88ab2adc22d48b384775d2b18d94b/native/nobel-eu/nobel-eu.txt).
  Source revision: `b8227125f9d88ab2adc22d48b384775d2b18d94b`.
  SHA-256: `2170d1f8d2b481dca907b4c17c33e292fd06a05bfef279e0d31f2f1f659bdfd0`.

Orlowski, Wessäly, Pióro and Tomaszewski, “SNDlib 1.0—Survivable Network
Design Library,” Networks 55 (2010), 276–286,

The official download endpoints were unavailable when investigated. The mirror
is not confirmed as an official distribution; provenance and permitted-use
