# Senior Software Engineer - 2026-2158

## Description

Quantum Sky is searching a Software Engineer to join our team building agent-powered applications for network automation and mission platforms. This is a hands-on development role focused on Python, Go, and modern front-end technologies within an AI-assisted, DevOps, CI/CD, and Infrastructure-as-Code environment.

The ideal candidate is a strong software engineer who is comfortable owning software across the full development lifecycle — from design and development through CI/CD, deployment, and production operations — and can effectively work across software development, cloud infrastructure, and platform teams. In this role, you will design and build AI agents, APIs, and modern front-end applications, including interfaces that generate and adapt themselves in real time using generative AI, instead of being hand-built screen by screen. This position also requires strong communication skills, with the ability to translate complex technical concepts into practical, actionable solutions for both technical and non-technical stakeholders.

## Responsibilities:

- Design, develop, test, and maintain full-stack application capabilities using Python and Go, with an emphasis on secure, scalable, maintainable, and production-ready software.
- Develop backend services, APIs, integrations, automation, and supporting tools using Python, Go, JavaScript/TypeScript, and other appropriate technologies.
- Build new product capabilities and enhance existing functionality across our network automation and mission platform applications, including backend services and user-facing application features.
- Build AI agent systems that use tools, call external services, and reason over structured and unstructured data.
- Integrate agents with tools and data sources using modern agent-tool protocols, including the Model Context Protocol (MCP).
- Design and build modern front-end applications, including generative UI, where components and layout are constructed dynamically based on user intent.
- Design and implement integrations with cloud services, network automation tools, monitoring solutions, and third-party systems using REST APIs and structured data.
- Develop capabilities that ingest, process, and correlate operational and telemetry data, and use agents to automate workflows across the platform.
- Work within a CI/CD and Infrastructure-as-Code environment maintained by the platform team, understanding how your code is provisioned, deployed, configured, and operated in production.
- Contribute to CI/CD pipelines that support automated builds, automated testing, and reliable deployment across development, staging, and production environments.
- Build and deploy containerized, cloud-native applications, working closely with the Cloud & Platform Engineer on scalability, reliability, observability, and performance.
- Use AI-assisted software development tools such as Claude Code, OpenAI Codex, Cursor, GitHub Copilot, or similar technologies as part of day-to-day engineering workflows to accelerate coding, debugging, refactoring, testing, documentation, and code analysis.
- Apply engineering judgment when working with AI-generated code and recommendations, validating outputs for correctness, security, maintainability, performance, and alignment with engineering standards.
- Troubleshoot complex application, integration, deployment, and production issues, identify root causes, and implement sustainable solutions.
- Participate throughout the software development lifecycle, including architecture and design discussions, code reviews, testing, documentation, release management, deployment, and continuous improvement of engineering practices.
- Apply secure software development practices throughout the application lifecycle, and collaborate with security and compliance staff to translate requirements into practical software capabilities.
